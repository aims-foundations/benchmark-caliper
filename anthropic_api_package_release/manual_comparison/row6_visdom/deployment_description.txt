Use case and domain: This is valid for government scientific facilities where you need to prepare a repository QA system for internal documents separated from the internet because of document sensitivity. Now the system is ideal for any country/organization based government facilities but you need to adapt the model so that it understands the documents from target domain.

Target population: Bangladesh Atomic Energy Commission. The language contains literature from the nuclear energy science domain in english and german languages. As well as, a separate official document repository that contains PDF documents in Bengali and English.
